# PDF Snipper Bot

একটা প্রজেক্ট করতে চাই ,,, যেখানে পিডিএফ দিলে সেখানে থাকা ( ধরো - ১-৫০০ টা পৃষ্ঠা আছে,সেখান থেকে ৩০-৫০ টা পৃষ্ঠা ই শুধু লাগবে আমার ঐকয়টা পৃষ্ঠার ই পিডিএফ দিবে হাই কুয়ালিটি+লো ফাইল সাইজ করে,,)



এমন টেলিগ্রাম বট বানাতে চাই,,,যেটা রেন্ডারে ফ্রি ডিপ্লয় করবো সেইভাবে সাজিয়ে দাও,, কতগুলো পৃষ্ঠার পিডিএফ সর্বোচ্চ দেয়া যাবে সেটাও বলবে
